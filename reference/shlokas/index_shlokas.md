## Structure of Each Shloka Entry

Each shloka contains:
1. **Sanskrit text** - Original Sanskrit in Devanagari script
2. **Transliteration** - Latin transliteration using standard romanization
3. **Translation** - English translation of meaning
4. **Context** - Explanation of which astrological concept it relates to

## How to Use These Shlokas

### For Reference:
- Use shlokas as citations in astrology notes
- Reference specific verses when explaining astrological principles
- Use as mnemonics for remembering astrological rules

### For Code Integration:
- The reference .md files can be parsed for:
  - Key concepts (e.g., karaka, dasha, transits)
  - Textual references to add to prediction engine
  - Educational content for users

### For Prediction Engine:

- Add astrological verses to prediction output
- Add traditional commentary to predictions
